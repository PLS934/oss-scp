## Why

#103: 보안팀과 개발팀이 홈에서 등록된 플러그인과 제공 데이터를 파악하고 조회 화면으로 이동할 수 있어야 한다. 기존 홈은 메뉴 선택 안내만 제공한다.

## What Changes

- 검증된 registry에서 공개 등록 요약 API를 제공한다.
- 선택 설명·활성화 설정(기본 true), 메뉴 생략을 지원한다.
- 홈에 등록 목록, 메뉴별 조회 링크 및 예외 상태를 표시한다.
- HTTP 출처는 인증정보·쿼리를 제외한 API 주소와 메서드, CSV 출처는 파일명을 표시한다.
- 원본 내려받기는 활성 로컬 CSV에만 제공하며 등록된 현재 파일의 바이트를 반환한다. API JSON과 HTTP CSV 다운로드는 제외한다.
- 설치·설정 편집·활성화 전환 UI, 연결·수집 성공 및 마지막 수집 시간은 제외한다.

## Capabilities

### New Capabilities
- `plugin-home`: 등록 정보와 유효한 조회 메뉴 탐색

### Modified Capabilities
- `plugin-source-contract`: 선택 설명·활성화·메뉴 설정과 비활성 실행 제외

## Impact

API, 웹, plugin-config와 기존 브라우저 CI 검증에 영향이 있다. 기존 plugin 설정은 호환된다. 새 선택 필드는 이를 지원하는 서버가 필요하며 새 홈과 서버를 함께 배포한다. 관련 이슈: #103.
