## Purpose

보안팀과 개발팀을 포함한 모든 웹 사용자가 계정 설정 없이 브라우저에서 화면 테마를 선택하고, 재방문과 운영체제 설정 변경에도 일관된 색상과 접근성을 제공받도록 한다.

## ADDED Requirements

### Requirement: 전역 테마 선택
웹은 모든 사용자에게 시스템 기본값으로 시작하고 상단 아이콘 클릭 시 현재 테마의 반대인 라이트·다크로 즉시 전환해야 한다(SHALL). 선택은 플랫폼의 브라우저 표시 설정이며 외부 수집 데이터 및 담당자 지정 정보에 영향을 주지 않아야 한다.

#### Scenario: 화면에서 테마 선택
- **WHEN** 사용자가 어느 경로에서든 라이트 또는 다크를 선택한다
- **THEN** 셸, 시작 화면, 플러그인 정의 기반 목록·상세, 상태 안내와 입력 컨트롤이 선택한 테마를 즉시 반영한다
- **AND** 현재 조회 데이터와 경로는 유지된다

### Requirement: 브라우저 선호 저장과 복원
웹은 선택을 해당 브라우저 출처에 저장하고 새로고침 및 다음 방문에서 복원해야 한다(SHALL). 저장값이 없거나 유효하지 않으면 시스템 설정을 사용해야 한다. 저장소 읽기·쓰기 실패는 화면 실행과 현재 세션의 선택을 막지 않아야 한다.

#### Scenario: 선택 복원
- **WHEN** 사용자가 라이트 또는 다크로 직접 전환한 뒤 새로고침하거나 같은 출처를 다시 방문한다
- **THEN** 저장된 선택과 그에 해당하는 색상이 복원된다

#### Scenario: 저장값 없음 또는 손상
- **WHEN** 저장된 선호가 없거나 허용되지 않은 값이다
- **THEN** 시스템 설정이 선택되고 현재 운영체제 색상 설정이 적용된다

#### Scenario: 저장소 접근 실패
- **WHEN** 브라우저 정책 또는 저장 공간 오류로 선호를 읽거나 쓸 수 없다
- **THEN** 앱을 정상적으로 사용할 수 있고 사용자의 새 선택은 현재 세션에 즉시 적용된다
- **AND** 다음 방문까지의 영속성을 보장하지 않는다

### Requirement: 운영체제 색상 설정 추적
웹은 시스템 설정 모드에서 현재 `prefers-color-scheme` 값과 실행 중 변경을 따라야 한다(SHALL). 명시적 라이트·다크 선택은 운영체제 변경에 의해 바뀌지 않아야 한다. 색상 선호를 조회할 수 없는 환경의 시스템 모드는 라이트로 표시해야 한다.

#### Scenario: 시스템 모드 변경
- **WHEN** 시스템 설정 모드에서 운영체제 색상 설정이 변경된다
- **THEN** 새로고침 없이 전체 화면 색상이 변경되고 선택값은 시스템 설정으로 유지된다

#### Scenario: 명시적 선택 유지
- **WHEN** 라이트 또는 다크를 선택한 상태에서 운영체제 색상 설정이 변경된다
- **THEN** 사용자가 선택한 색상은 유지된다

### Requirement: 첫 표시 테마 일치
웹은 초기 배경과 앱의 첫 표시부터 저장된 선호 또는 시스템 기본값으로 결정한 테마를 적용해야 한다(SHALL). 저장된 선택과 다른 색상이 먼저 표시되는 눈에 띄는 깜빡임이 없어야 한다.

#### Scenario: 반대 시스템 설정에서 재방문
- **WHEN** 다크 저장값과 라이트 운영체제 설정 또는 그 반대 조합으로 페이지를 새로 연다
- **THEN** 앱 코드 로딩 중 배경과 첫 앱 화면 모두 저장된 테마 색상으로 표시된다

### Requirement: 테마 접근성과 일관된 색상
웹은 의미 기반 공통 색상을 두 테마에 일관되게 적용해야 한다(SHALL). 일반 텍스트는 배경 대비 4.5:1 이상, 큰 텍스트는 3:1 이상, 필수 컨트롤 경계와 포커스 표시는 인접 색상 대비 3:1 이상이어야 한다. 상태는 색상과 함께 텍스트로 전달하고 테마 선택에는 접근 가능한 이름과 현재 선택 상태가 있어야 한다.

#### Scenario: 키보드 선택
- **WHEN** 사용자가 키보드만으로 테마 선택 컨트롤에 접근하고 값을 변경한다
- **THEN** 포커스가 보이며 선택이 적용되고 보조 기술이 현재 선택값을 파악할 수 있다

#### Scenario: 주요 화면 대비
- **WHEN** 시작·목록·상세 및 성공·실패·부분 결과·빈 값·오류 안내를 각 테마로 표시한다
- **THEN** 텍스트와 필수 컨트롤·포커스가 규정된 대비를 만족하고 상태 의미가 색상만으로 전달되지 않는다



최종 사용자 결정: 저장된 선택이 없으면 시스템 테마를 따른다. 태양 버튼을 누르면 다크(달), 달 버튼을 누르면 라이트(태양)로 즉시 전환하고 명시적 선택을 저장한다. 팝오버와 시스템 설정 선택 UI는 제공하지 않는다. 버튼은 전환 대상 이름을 보조 기술에 제공하며 Enter·Space로 조작한다.
