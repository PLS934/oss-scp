## MODIFIED Requirements

### Requirement: 유효한 조회 메뉴로 이동한다
홈은 각 등록 플러그인의 설정 상세 링크를 SHALL 제공하고 활성 플러그인의 검증된 메뉴에만 데이터 보기 링크를 SHALL 제공해야 한다. 설정 상세 링크는 플러그인 제목 옆 오른쪽 화살표 아이콘으로 제공하고 접근성 이름과 툴팁으로 목적을 명시해야 한다(MUST). 데이터 조회 링크는 플러그인 이름 바로 아래의 `{메뉴 그룹} > {메뉴 이름}` 텍스트로 표시하고 개별 메뉴 그룹·메뉴 이름 행은 제공하지 않는다. 복수 메뉴는 각 메뉴 위치를 별도 링크로 표시한다.

#### Scenario: 설정 상세 링크 선택
- **WHEN** 사용자가 등록된 플러그인의 제목 옆 설정 상세 화살표를 선택한다
- **THEN** 해당 플러그인 ID의 읽기 전용 설정 상세 경로로 이동한다

#### Scenario: 조회 링크 선택
- **WHEN** 사용자가 메뉴 위치 링크를 선택한다
- **THEN** 해당 메뉴의 기존 레코드 목록 경로로 이동한다

#### Scenario: 이동할 수 없는 플러그인
- **WHEN** 플러그인이 비활성이거나 조회 메뉴가 없다
- **THEN** 데이터 조회 링크 없이 이유를 안내하되 등록된 플러그인의 설정 상세 링크는 유지한다
