## MODIFIED Requirements

### Requirement: 처리 완료와 제한된 보관
수집기는 SHALL 전체 single 응답을 검증한 뒤 처리 함수를 최대 한 번 호출하고 그 완료를 기다려야 하며, 처리 완료 데이터나 원천 응답을 실행 결과에 중복 보관하지 않아야 한다. 처리 함수와 호출자가 원천 응답 참조를 보관하지 않는 경우, 수집 완료 후 수집기 자체가 보관하는 메모리는 처리한 원천 응답 크기에 비례하여 증가하지 않아야 한다.

#### Scenario: 느린 처리 완료 대기
- **WHEN** 처리 함수가 아직 완료되지 않았다
- **THEN** 수집 작업은 정상 완료를 반환하지 않는다

#### Scenario: 처리 실패
- **WHEN** 처리 함수가 실패한다
- **THEN** 수집기는 처리 오류를 호출자에게 전파하고 정상 완료를 반환하지 않는다

#### Scenario: 큰 유효 응답의 제한된 실행 결과
- **WHEN** 설정 한도 안의 큰 single 목록을 성공적으로 처리하고 처리 함수가 원천 데이터 참조를 보관하지 않는다
- **THEN** 수집 결과는 요청·레코드 건수의 작은 요약만 포함하며, 수집기 자체의 완료 후 보관량은 원천 응답 크기에 비례하여 증가하지 않는다
