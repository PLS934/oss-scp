## 1. 상세 계약과 로더 투영

- [x] 1.1 `ClientPluginDetail` source variant·데이터·화면·transform 상태 타입을 추가하고 타입 검사로 공개 계약을 검증한다.
- [x] 1.2 설정 로더가 검증된 runtime 정의에서 상세 DTO와 안전한 transform 후보를 생성하도록 구현하고 HTTP JSON·CSV·라이브 DB·중첩 필드·관계·비밀정보 제외 단위 테스트를 통과시킨다.
- [x] 1.3 runtime registry가 상세 DTO를 immutable하게 보관하고 ID 조회를 제공하도록 구현하며 입력 변경과 내부 경로 비노출 회귀 테스트를 통과시킨다.

## 2. 읽기 전용 상세 API

- [x] 2.1 등록된 transform 후보만 realpath·일반 파일·no-follow·inode·크기 제한으로 읽는 모듈을 구현하고 TypeScript 우선·JavaScript fallback·누락·루트 이탈·심볼릭 링크·크기 초과 테스트를 통과시킨다.
- [x] 2.2 `GET /api/v1/plugins/:id`가 상세 DTO와 transform 상태를 반환하고 없는 ID는 `PLUGIN_NOT_FOUND` 404를 반환하도록 구현하며 API 정상·실패 테스트를 통과시킨다.
- [x] 2.3 상세 조회가 파일·registry·수집·저장 상태를 변경하지 않고 오류에 내부 경로나 운영체제 원인을 노출하지 않음을 API 회귀 테스트로 검증한다.

## 3. 웹 설정 상세 화면

- [x] 3.1 상세 API client와 런타임 응답 검증을 구현하고 모든 source variant·중첩 필드·관계·transform 상태 및 잘못된 응답 테스트를 통과시킨다.
- [x] 3.2 `/plugins/:pluginId` route와 로딩·성공·404·API 실패 상태를 구현하고 직접 URL 및 route 변경 테스트를 통과시킨다.
- [x] 3.3 기본 정보·수집 설정·데이터 구조·가공 코드·화면 구성 섹션을 읽기 전용으로 렌더링하고 source 차이·중첩 계층·관계·코드 종류·코드 실패 표시 테스트를 통과시킨다.
- [x] 3.4 홈의 플러그인 이름을 설정 상세 링크로 바꾸되 기존 데이터 보기 링크와 비활성·메뉴 없음 동작을 유지하고 홈 회귀 테스트를 통과시킨다.
- [x] 3.5 기존 디자인 토큰과 반응형 패턴으로 상세 화면 스타일을 추가하고 웹 빌드로 CSS와 화면 번들 생성을 검증한다.
- [x] 3.6 홈의 화살표를 설정 상세 링크로, 메뉴 경로를 데이터 조회 링크로 바꾸고 비활성·복수 메뉴·접근성 회귀 테스트와 웹 빌드를 통과시킨다.
- [x] 3.7 브라우저 통합 테스트가 활성·비활성·메뉴 없음 플러그인의 설정 상세 링크와 데이터 조회 링크를 새 동선에 맞게 검증하도록 갱신한다.
