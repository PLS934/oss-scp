## MODIFIED Requirements

### Requirement: 최소 플러그인 선언
플랫폼은 플러그인의 계약 버전, 고유 식별자, 표시 이름, 릴리스 버전, 상대 source 파일 경로, 상대 가공 모듈 경로, 데이터 정의와 단일 메뉴 선언을 외부 설정 루트의 `plugin.json`에서 선언할 수 있게 SHALL 제공해야 한다. 메뉴 선언은 제목, 지원 아이콘, 그룹, 정렬 순서, 절대 경로와 대상 데이터 종류를 포함해야 한다. 데이터 정의는 하나 이상의 데이터 종류, 각 종류의 필드와 타입, 필수 여부, 유일키 및 선택적 관계를 포함해야 하며 가공·화면 외의 지원하지 않는 설정을 필수로 요구하지 않아야 한다. 가공 모듈은 운영 배포 전에 생성된 JavaScript여야 하며(MUST), 플랫폼은 그 모듈의 요구 export를 기동 전에 검증해야 한다.

#### Scenario: 유효한 sample1 플러그인
- **WHEN** 운영자가 지원 계약 버전, 유효한 상대 source·사전 빌드 JavaScript 가공 모듈 경로, 완전한 데이터 정의와 유효한 메뉴 선언을 가진 sample1 `plugin.json`을 외부 설정 루트에서 검증한다
- **THEN** 플랫폼은 해당 플러그인 선언을 실행 가능한 플러그인으로 승인하고 내부 수집 정의에 가공 모듈, 데이터 정의와 메뉴를 포함한다

#### Scenario: 등록된 sample2와 CSV 플러그인
- **WHEN** sample2와 CSV 샘플 플러그인이 외부 registry에 등록되어 있고 각각 유효한 가공 모듈, 데이터 정의와 메뉴 선언을 제공한다
- **THEN** 플랫폼은 source 형식과 무관하게 두 플러그인의 내부 정의에도 가공 모듈, 데이터 정의와 메뉴를 포함한다

#### Scenario: 잘못된 플러그인 선언
- **WHEN** 계약 버전이나 필수 식별·메뉴 정보가 없거나 source·가공 모듈 경로가 플러그인 디렉터리 밖을 참조한다
- **THEN** 플랫폼은 문제 필드와 플러그인을 식별할 수 있는 오류로 선언을 거부한다

#### Scenario: 심볼릭 링크를 통한 경로 이탈
- **WHEN** registry, source, 로컬 파일 또는 가공 모듈의 해석된 실제 경로가 심볼릭 링크를 통해 허용된 외부 설정 루트 밖을 가리킨다
- **THEN** 플랫폼은 루트 밖의 파일을 읽거나 실행하지 않고 해당 참조를 거부한다

#### Scenario: 유효하지 않은 데이터 참조
- **WHEN** 유일키 또는 메뉴가 선언되지 않은 필드를 가리키거나 관계 또는 메뉴가 존재하지 않는 데이터 종류를 참조한다
- **THEN** 플랫폼은 외부 요청과 가공 모듈 실행 전에 해당 참조를 명시한 오류로 선언을 거부한다

#### Scenario: 지원하지 않는 메뉴 아이콘
- **WHEN** 플러그인 메뉴가 플랫폼의 고정 허용 목록에 없는 아이콘을 선언한다
- **THEN** 플랫폼은 대체 아이콘으로 조용히 변경하지 않고 해당 메뉴 선언을 검증 오류로 거부한다

#### Scenario: 가공 모듈 파일 누락
- **WHEN** 등록된 플러그인의 가공 모듈이 없거나 JavaScript가 아니거나 요구된 export를 제공하지 않는다
- **THEN** 플랫폼은 다른 경로의 파일을 대신 실행하거나 코드를 변환하지 않고 해당 플러그인의 검증을 실패한다

#### Scenario: 등록된 샘플 중 필수 가공 계약 누락
- **WHEN** sample1, sample2 또는 CSV를 포함한 등록 플러그인 중 하나가 가공 모듈, 데이터 정의 또는 메뉴 선언을 제공하지 않는다
- **THEN** 플랫폼은 누락된 플러그인과 필드를 보고하고 전체 설정 검증을 성공으로 표시하지 않는다
