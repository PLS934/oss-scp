## Why

현재 구현은 핵심 수집·저장·조회 경로를 검증하고 있지만, 개발 플랜은 첫 정식 릴리스인 1.0.0의 광범위한 MVP 범위만 정의한다. 폐쇄망 단일 서버에서 현재 결과를 평가하려는 운영자가 0.1.0의 지원 범위와 제한, 출시 차단 조건을 일관되게 판단할 수 있도록 기술 프리뷰 계약을 먼저 확정해야 한다.

## What Changes

- 0.1.0을 Registry 접근이 없는 폐쇄망 단일 서버용 기술 프리뷰로 정의한다.
- 0.1.0의 필수 사용자 여정을 오프라인 설치, 명시적 DB migration, 외부 플러그인 설정 주입, 수집, 저장된 목록·상세 조회, 업데이트와 복구 검증으로 한정한다.
- PostgreSQL 17.6과 MySQL 8.4.6을 검증 대상 DB로, Docker Compose 기반 linux/amd64를 검증 대상 배포 환경으로 명시한다.
- LDAP·권한·담당자·감사·보관/삭제·일일 스케줄·검색/필터/정렬·운영 화면 등 1.0.0 MVP 작업을 0.1.0 지원 범위에서 제외하고 알려진 제한 사항으로 공개한다.
- 0.1.0 릴리스 게이트를 #70, #71, #88, #89 완료, 최종 태그 커밋 전체 CI 성공, 산출물 설치·업데이트·복구 검증으로 정의한다.
- 0.x 개발 릴리스와 1.0.0 정식 릴리스의 지원 기대치와 완료 기준을 분리해 문서화한다.
