## Why

웹 클라이언트가 실제 아이콘 컴포넌트 대신 아이콘 이름의 한글 텍스트를 메뉴 제목 앞에 출력하여 `서버 서버 자산`, `저장소 저장소`처럼 제목이 중복된다. 아이콘 렌더러가 준비되지 않은 메뉴에서도 사용자가 선언된 메뉴 제목을 정확히 읽을 수 있어야 한다.

## What Changes

- 실제로 렌더링할 수 있는 아이콘이 등록된 경우에만 메뉴 제목 앞에 아이콘을 표시한다.
- 아이콘 렌더러가 없는 경우 아이콘 텍스트나 빈 영역 없이 메뉴 제목만 표시한다.
- 서버 자산과 저장소 메뉴의 중복 표시를 막는 웹 회귀 테스트를 추가한다.
- 아이콘 컴포넌트나 아이콘 라이브러리를 새로 도입하는 작업은 포함하지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `plugin-menu-routing`: 검증된 registry의 아이콘 식별자를 실제 렌더러가 있는 경우에만 시각 요소로 표시하고, 렌더러가 없으면 제목만 표시하도록 메뉴 표시 요구사항을 구체화한다.

## Impact

- 웹 사이드바 메뉴 렌더링과 관련 자동화 테스트가 영향을 받는다.
- 플러그인 manifest, 메뉴 API 응답, schema, 의존성 및 서버 동작은 변경하지 않는다.
