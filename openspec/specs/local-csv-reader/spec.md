# local-csv-reader Specification

## Purpose

로컬 CSV 파일을 읽기 전용으로 순회해 원천 문자열을 보존하는 객체를 제공한다. 파일 획득과 파싱을 분리하여 후속 수집 경로에서도 동일한 형식 처리를 재사용한다.

## Requirements

### Requirement: 문자열 행 반환
시스템은 UTF-8(선택 BOM), 쉼표 구분, 큰따옴표와 이중 큰따옴표 escape, LF·CRLF·CR 줄바꿈을 지원하고 첫 행을 헤더로 사용해야 한다(SHALL). 값의 공백·빈 문자열·숫자 표기를 보존한다. 빈 줄은 무시하며 빈 파일은 실패, 헤더만 있는 파일은 0행이다. 빈 헤더·중복 헤더·열 수 불일치·잘못된 따옴표·잘못된 UTF-8은 거부한다.

#### Scenario: 샘플 순회
- **WHEN** 제공된 vulnerabilities.csv를 읽는다
- **THEN** 순서대로 53개 객체와 각각 6개 필드를 반환하고 10.0·0.10을 문자열로 유지한다

#### Scenario: 복합 문자열
- **WHEN** 인용된 필드에 쉼표·줄바꿈·큰따옴표가 포함된다
- **THEN** 필드 구분으로 오인하지 않고 원래 문자열을 반환한다

#### Scenario: 잘못된 입력
- **WHEN** 헤더·열 수·인용·UTF-8이 계약에 어긋난다
- **THEN** 형식 오류로 순회를 중단한다

### Requirement: 제한된 순차 읽기
시스템은 전체 파일을 메모리에 모으지 않고 소비 속도에 맞춰 행을 반환해야 한다(SHALL). 기본 입력 한도 1 GiB와 파서 레코드 버퍼 한도 1 MiB를 적용하고 양의 안전한 정수 옵션으로 조정할 수 있다. 초과는 실패로 처리하며 조기 순회 종료 시 자원을 닫는다.

#### Scenario: 느린 소비와 중단
- **WHEN** 대량 입력의 첫 행만 소비하고 순회를 중단한다
- **THEN** 전체 입력을 읽지 않고 입력 자원을 해제한다

#### Scenario: 크기 초과
- **WHEN** 입력 또는 레코드가 설정 한도를 넘는다
- **THEN** 한도 초과 오류로 종료한다

### Requirement: 파일 오류와 완료 판정
시스템은 파일 없음, 접근·읽기 실패, CSV 형식 오류, 한도 초과, 파일 변경을 구분해야 한다(SHALL). 로컬 일반 파일만 읽으며 시작·종료의 파일 식별·크기·수정 메타데이터가 다르면 실패한다. 전달된 일부 행은 전체 성공을 뜻하지 않는다. 업무 저장·권한·담당자 변경은 수행하지 않는다.

#### Scenario: 파일 장애
- **WHEN** 파일이 없거나 읽기 권한이 없거나 읽는 중 오류가 발생한다
- **THEN** 해당 오류를 반환하고 정상 완료로 보고하지 않는다

#### Scenario: 파일 수정
- **WHEN** 순회 중 파일이 수정되거나 경로가 다른 파일로 교체된다
- **THEN** 완료 검증에서 변경 오류를 반환한다
