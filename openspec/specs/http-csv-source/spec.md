# http-csv-source Specification

## Purpose

HTTP API에서 CSV를 제한된 스트림으로 받아 공통 CSV 형식 계약에 따라 행 묶음으로 전달하고, 완전한 다운로드와 파싱만 성공으로 판정하게 한다.

## Requirements

### Requirement: HTTP CSV 스트리밍 수집
플랫폼은 HTTP GET 응답을 전체 파일에 비례하는 메모리로 모으지 않고 CSV 행으로 파싱하여 설정된 최대 행 수의 묶음으로 SHALL 전달해야 한다. CSV 값과 순서는 로컬 CSV 경로와 동일하게 보존해야 하며 느린 묶음 소비 시 네트워크 읽기에 backpressure를 적용해야 한다.

#### Scenario: 등록된 취약점 CSV 다운로드
- **WHEN** 등록된 샘플 플러그인으로 mock API의 `vulnerabilities.csv`를 수집한다
- **THEN** 플랫폼은 53행과 각 행의 6개 필드를 중복·누락 없이 20·20·13개 묶음으로 전달하고 `10.0`, `0.10`을 문자열로 유지한다

#### Scenario: 로컬과 HTTP 결과 일치
- **WHEN** 동일한 CSV를 로컬 파일과 HTTP 다운로드 source로 각각 끝까지 수집한다
- **THEN** 두 경로가 반환한 행의 순서, 필드와 문자열 값이 모두 일치한다

#### Scenario: 다른 CSV API
- **WHEN** 운영자가 다른 요청 경로와 CSV 헤더·행 수를 가진 유효한 HTTP source를 별도 플러그인으로 등록한다
- **THEN** 플랫폼은 샘플 전용 필드를 코어에 추가하지 않고 선언된 source를 수집한다

#### Scenario: 느린 묶음 소비
- **WHEN** 수집 소비자가 다음 묶음 처리를 늦춘다
- **THEN** 플랫폼은 소비 속도에 맞춰 다운로드 읽기를 제한하고 완료된 묶음을 전체 파일 크기에 비례해 누적하지 않는다

### Requirement: 다운로드 및 파싱 한도
플랫폼은 요청 timeout, 전송 바이트, 압축 해제 후 CSV 바이트, 단일 CSV 레코드와 묶음 행 수에 설정된 한도를 SHALL 적용해야 한다. `Content-Length`는 사전 거부와 길이 일치 검증에 사용할 수 있지만 실제 수신 바이트 검사를 대체하지 않아야 하며, 지원하는 압축 응답에는 전송 전후 한도를 모두 적용해야 한다.

#### Scenario: Content-Length 없는 크기 초과
- **WHEN** chunked 응답의 실제 수신 바이트가 다운로드 한도를 넘는다
- **THEN** 플랫폼은 스트림을 중단하고 크기 초과 오류를 반환한다

#### Scenario: 압축 해제 후 크기 초과
- **WHEN** 지원되는 압축 응답의 전송 크기는 한도 안이지만 해제된 CSV 바이트가 한도를 넘는다
- **THEN** 플랫폼은 파싱을 중단하고 크기 초과 오류를 반환한다

#### Scenario: 레코드 크기 초과
- **WHEN** CSV 레코드 하나가 설정된 레코드 한도를 넘는다
- **THEN** 플랫폼은 해당 입력을 실패로 처리하고 완료로 표시하지 않는다

### Requirement: 완료·실패·취소 구분
플랫폼은 HTTP 응답 본문을 끝까지 받고 길이·압축·CSV 파싱 검증과 마지막 묶음 처리가 모두 성공한 경우에만 해당 수집 범위를 완료로 SHALL 표시해야 한다. HTTP 오류, timeout, 취소, 중도 연결 종료, 선언 길이 불일치, 지원하지 않거나 잘못된 압축, CSV 형식, 한도 초과와 묶음 처리 실패를 구분하고, 실패·취소·조기 종료 시 네트워크·파서 자원을 해제해야 한다.

#### Scenario: 중도 연결 종료
- **WHEN** 서버가 선언한 응답을 모두 보내기 전에 연결을 종료한다
- **THEN** 플랫폼은 이전에 전달한 묶음을 포함해 전체 성공으로 보고하지 않고 불완전 다운로드 오류를 반환한다

#### Scenario: 요청 timeout과 취소
- **WHEN** 다운로드가 timeout을 넘거나 호출자가 취소 신호를 보낸다
- **THEN** 플랫폼은 두 원인을 구분해 종료하고 응답 스트림과 파서를 정리한다

#### Scenario: 묶음 처리 실패
- **WHEN** 소비자가 전달된 묶음을 처리하지 못한다
- **THEN** 플랫폼은 후속 다운로드를 중단하고 처리 실패를 반환하며 완료로 표시하지 않는다

#### Scenario: 비밀정보 없는 오류
- **WHEN** HTTP CSV 수집이 실패한다
- **THEN** 오류에는 URL query, 인증 값, 응답 본문 또는 CSV 원문을 포함하지 않고 원인 코드와 안전한 원천 위치만 포함한다
